# Meha Patel — Data Science & Statistics Portfolio

Data scientist and statistician working at the intersection of **statistical
modeling, machine learning, and applied research**. My background spans
undergraduate and graduate coursework in mathematics and statistics, published
undergraduate research in numerical optimization, and applied work in
biostatistics and process analytics.

This repository is a curated, self-contained portfolio: each project lives in
its own folder with the source code, the data (where it can be shared), and a
README that explains the problem, the approach, and the results.

## Highlights

- **Published research.** The μ-mSCD project is co-authored work on solving
  large-scale linear systems with missing data, published in *SIAM Undergraduate
  Research Online (SIURO)*. It proves the proposed estimator is unbiased in
  expectation and validates the method on synthetic and real-world data.
- **Applied biostatistics.** The network meta-analysis answers a real clinical
  question — how galcanezumab compares to other chronic-migraine preventives —
  using indirect evidence synthesis and a written results report.
- **Range of tooling.** Projects span R, Python, and MATLAB, and cover the full
  arc from low-level algorithm implementation to applied modeling on real data.
